Star Renegades Rebalance 0.3.2

Test release for Windows x64, Steam build 1.5.1.5.

Includes the shared fixes from Bugfix Mod 0.1.3: Illuminate self-deactivation,
selected-partner Shadow Puppets effect routing and Hard Reset's corrected
English description. The existing character and alternate-form buffs,
eight combo adjustments and four camping cost reductions are retained.

Download Star-Renegades-Rebalance-v0.3.2.zip, extract it, close the game and
run Install.cmd. Existing public Rebalance installations update directly.
No earlier version is required for a first install. Install one mod at a
time; this package already contains the shared Bugfix repairs.

Hard Reset's missing shield-recharge effect remains unresolved. Remaining
enemy references have no established replacements and are held. Actual
combo battles and Entropy V roster balance still need playtesting.

The source ZIP includes both projects, their tests and dependency notices.
No game assemblies, full game tables or saves are included.

Shadow Puppets participant routing and effect consumption are tested.
Rescheduling of already queued actions still needs normal battle testing.
