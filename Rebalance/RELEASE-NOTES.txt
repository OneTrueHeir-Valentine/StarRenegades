Star Renegades Rebalance 0.3.3

Test release for Windows x64, Steam build 1.5.1.5.

Includes Bugfix Mod 0.1.4's healing cap, temporary armor, effect cancellation,
immunity, tether and ally guard forecast corrections. These change forecasts;
executed combat and the existing character, alternate-form, combo and
camping balance values are unchanged. All previous shared repairs remain.

Download Star-Renegades-Rebalance-v0.3.3.zip, extract it, close the game and
run Install.cmd. Existing public Rebalance installations update directly.
No earlier version is required for a first install. Install one mod at a
time; this package already contains the shared Bugfix repairs.

Cross-round expiry and other unmodeled effects remain under investigation.
Hard Reset's missing recharge effect and uncertain enemy replacements stay
held. Full battles, rendered UI and Entropy V roster balance need playtesting.

The source ZIP includes both projects, their tests and dependency notices.
No game assemblies, full game tables or saves are included.

CHANGELOG.txt lists this update; the root changelog explains shared repairs.
