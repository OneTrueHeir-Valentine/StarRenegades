Star Renegades Rebalance 0.3.1

Test release for the Windows x64 Steam version of Star Renegades 1.5.1.5.
Includes every fix in Bugfix Mod 0.1.2.

The aim is to make every base renegade and alternate form a strong starter
choice on Entropy V. This build retains the approved character and variant
changes, eight combo buffs and four camping cost reductions. That goal
still needs playtesting across forms, equipment and team compositions.

INSTALL

1. Download Star-Renegades-Rebalance-v0.3.1.zip from:
   https://github.com/OneTrueHeir-Valentine/StarRenegades/releases
2. Extract it into its own folder. Close the game.
3. Double-click Install.cmd. Select the Steam game folder if requested.
4. Start the game normally through Steam.

No earlier rebalance version is required. Dependencies are included.
Windows may ask for administrator permission for a Program Files library.
Keep the extracted folder for Uninstall.cmd and future troubleshooting.

Choose this mod or Bugfix Mod. Rebalance already includes its fixes;
installing both is unsupported. To switch, uninstall the active mod first.
An older private rebalance without an installer receipt is not upgraded
automatically. Restore or remove it using that version's own backup and
uninstaller before installing this release. Never delete your saves.

CHANGES

Character and variant buffs retain their level scaling and unlock routes.
Mind Scythe retains the damage advantage added after the Psion Knife buff.
The live skill values and edited English descriptions reflect the data.

Pamphlet, Soul Soothing and Optimizations cost one camping point. Reborn
costs two. The camping budget, card effects and affection are unchanged.
Eight combo attacks receive damage, Fury or shield adjustments, detailed
in CHANGELOG.txt and explained in CHANGE-RATIONALE.txt.

Item rarity and level progression are retained. Damage-bonus references,
missing affix pools and blaster affix tags use the shared Bugfix repairs.
Previously empty saved random rolls are not rerolled. Fresh drops use the
corrected pools. Exact developer intent for those pools remains uncertain;
they mirror the working sword pools at the matching grade and level.

Enemy choices now follow their declared weights. Dragoon Overseer summon
and Panzer repair continuations are repaired. These corrections can make
encounters harder. Forecast, camping text and achievement repairs are also
included. The mod does not edit saves or grant achievement progress.

TESTING

Automated checks cover both overlays together, every listed data change,
shared hook activation, rollback, installer recovery and release contents.
They do not establish Entropy V balance for every form or eliminate every
forecast error, loading failure or softlock.

Report issues with your game/mod versions and reproduction steps at:
https://github.com/OneTrueHeir-Valentine/StarRenegades/issues
The log is SRRebalance/rebalance.log inside the game folder. Remove any
personal paths before sharing it. Screenshots of predicted and actual
results are useful when a forecast differs.

BUILD.txt explains contributor builds. Local game files are required and
are not distributed. This is an unofficial mod.
