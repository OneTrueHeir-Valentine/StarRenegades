# Star Renegades Bugfix Mod 0.1.0

Test release for Windows x64, Steam build 1.5.1.5.

Download `Star-Renegades-Bugfix-Mod-v0.1.0.zip`, extract it, close the game and run `Install.cmd`. Launch through Steam as usual. Run `Uninstall.cmd` from the extracted release to remove it.

Includes item effects, missing affix pools, camping text and relationship-preview fixes, plus three reproduced combat forecast corrections. See the README and changelog for the complete list. This release keeps the base game's balance and existing saved item rolls.

Automated engine and installer checks pass. Normal Steam launch and rendered HUD previews need manual testing before a stable release. Further forecast problems may remain.

The separate source ZIP contains the mod source and dependency notices. Neither ZIP includes game assemblies, full game tables or save files.
