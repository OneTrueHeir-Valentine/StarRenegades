Star Renegades Bugfix Mod 0.1.4

Test release for Windows x64, Steam build 1.5.1.5.

Corrects combat forecasts for healing caps, temporary armor, source and
party cleanses, projected debuff immunity, tethered guard/counter/overwatch
effects and ally support routing. Counterattacks consume forecast source
effects when their native action does. Tethered grants fail together when
an effect is resisted.

Excess healing could previously hide a later lethal hit. Existing Spy mode
armor was omitted when a forecast started. These repairs change forecasts;
executed combat and balance values are unchanged. All previous fixes remain.

Download Star-Renegades-Bugfix-Mod-v0.1.4.zip, extract it into a new folder,
close the game and run Install.cmd. Existing Bugfix installations update
directly. Rebalance 0.3.3 has a separate download and includes these fixes.
Install one mod at a time. Keep the extracted folder for Uninstall.cmd.

Native-method tests cover the reproduced cases and live-state isolation.
Full battles and rendered UI still need testing. Cross-round expiry,
further forecast errors and loading failures remain under investigation.
The source ZIP includes tests and dependency notices, with no game
assemblies, full tables or saves. CHANGELOG.txt explains the changes.
