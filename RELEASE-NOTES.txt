Star Renegades Bugfix Mod 0.1.2

Test release for Windows x64, Steam build 1.5.1.5.

This update corrects weighted enemy action selection and repairs two
broken enemy continuations: Dragoon Overseer summoning and Panzer repair.
Some encounters can become harder because their existing definitions now
work. All item, text, forecast and achievement fixes from 0.1.1 remain.

Download Star-Renegades-Bugfix-Mod-v0.1.2.zip, extract it into a new folder,
close the game and run Install.cmd. Existing Bugfix installations can be
updated directly. Launch through Steam as usual. Keep the extracted folder
and run Uninstall.cmd to remove the mod.

Rebalance has a separate download and release tag in this repository.
It includes these fixes. Install one mod at a time.

Automated checks cover the native methods, activation rollback, installer
recovery and package contents. The new enemy behavior still needs normal
game playtesting. Loading softlocks and other forecast discrepancies may
remain. The mod does not edit saves or add achievement progress.

The source ZIP contains the mod source, tests and dependency notices.
Neither ZIP includes game assemblies, full game tables or saves.
